# Jacobson Sisters' Norway

A single-page family-history site: the Norwegian ancestry of Gertrude Betty Jacobson (1921–2015) and her sisters, with a map of birthplaces, an expandable pedigree, and the Norwegian records that prove each link.

Everything is in `index.html`. It loads only two external things: the D3 library from cdnjs and three fonts from Google Fonts.

## Publish on GitHub Pages
1. Create a repository (public, or private on a paid plan) and upload `index.html` and this README.
2. Settings → Pages → Source: "Deploy from a branch", branch `main`, folder `/ (root)`. Save.
3. After a minute the site is at `https://<username>.github.io/<repository>/`.
